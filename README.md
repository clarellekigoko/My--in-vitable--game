# My--in-vitable--game
 Concept : Un petit jeu romantique 2D* Le joueur (toi) doit traverser des obstacles (distance, doutes) pour rejoindre ton "Abri Beau". Chaque niveau que tu passes, un petit mot d'amour s'affiche. *Fonctionnalités simples :* - 3 niveaux - Musique douce - À la fin : "Tu étais mon évidence" + photo de vous deux -
